**SaaS de facturación y presupuestos** pensado para autónomos y pymes.

<img src="https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white" />

- Backend con **Supabase** (PostgreSQL): esquema completo con Row Level Security (RLS) y triggers para el alta automática de organización y usuario en el registro.
- Generación de presupuestos y facturas en PDF con **react-pdf**.
- Dashboard con visualizaciones y gestión de presupuestos.
- Arquitectura multi-tenant (organización → usuarios → clientes → presupuestos).
